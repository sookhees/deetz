# Deetz

Deetz answers questions from a person's own Microsoft 365, their files,
SharePoint, mail, calendar and Teams, by voice or by text, running inside the
organisation's own Azure tenant. Every search runs as the person asking, so an
answer can only contain what they could already find for themselves, and no
content is copied out of the tenant.

**Status: nothing to install yet.** Deetz is being built in public, one
working commit at a time. What is here today is the landing page.
